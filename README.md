# Wireframe.arch — Interactive Web Architecture & Layout Reference

A zero-build, lo-fi neutral wireframe reference website cataloging standard web layout patterns, typography hierarchy, and interactive UI components.

## Highlights
- **6 Realistic Page Templates**: Landing Page, Editorial / Article, Dashboard / App Shell, E-Commerce PDP, Auth & 404, Design Tokens, plus an About / Development Log page.
- **Inline Variant Switchers**: Swap Navbar (`Standard`, `Centered Brand`, `With Search`, `Mega Menu`), Hero (`Split`, `Centered Banner`, `Immersive Full-Bleed`), Features (`Bento Grid`, `Zig-Zag`, `Card Grid`), Timeline (`Stepper`, `Vertical`), and Gallery (`Carousel`, `9:16 Masonry`, `Marquee`) in place.
- **Hybrid Inspection Mode**:
  - **Hover** any component to identify its name & category.
  - **X-Ray Mode (`[X]`)** to reveal all wireframe boundaries and labels.
  - **12/8/4-Column Grid Overlay (`[G]`)** to verify layout alignment.
  - **Click Inspector** showing semantic HTML tag, live pixel dimensions, guidelines, **Copy Spec**, and **Shareable Deep Link**.
  - **Command Palette (`⌘K`)** with bilingual search and auto-jump to hidden variants.
- **Bilingual (EN / 中文)** & **Responsive Preview** (`Desktop`, `Tablet 768px`, `Mobile 390px`).

## Files
- `index.html` — Main interactive wireframe reference site
- `tokens-preview.html` — Standalone Design Token specification sheet

- `css/wireframe.css` — Wireframe components & responsive Container Queries
